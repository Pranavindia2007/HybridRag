HybridRAG for Semiconductor Datasheets

Offline, local-first datasheet RAG for engineers who need exact register, bit-field, pinout, package, timing, and electrical answers with citations.

View the GitHub repository Read the README

What It Does

HybridRAG turns dense semiconductor chip datasheets and embedded hardware specifications into a searchable engineering assistant. It combines Docling PDF parsing, table-aware chunking, ChromaDB vector search, BM25 exact matching, Ollama vision summaries for technical diagrams, and a NetworkX/docling-graph knowledge graph.

Hybrid retrieval
Dense embeddings plus BM25 reciprocal-rank fusion for semantic and exact-symbol search.
Atomic tables
Register maps and bit-field tables are kept intact for precise hardware lookup.
Knowledge graph
Datasheet entities such as packages, pins, peripherals, registers, and timing parameters become traversable graph nodes.
Local-first
Runs with local Ollama models so private datasheets do not need to leave your machine.

Search-Friendly Use Cases

  • Semiconductor datasheet RAG and technical PDF retrieval.
  • Offline RAG chatbot for ASIC, SoC, MCU, and embedded systems documentation.
  • Register map search, bit-field lookup, reset value lookup, and pinout search.
  • Graph RAG for datasheet entities with page-level provenance and citations.
  • Docling-based parsing for hardware specifications with tables and diagrams.

Quick Start

git clone https://github.com/Pranavindia2007/HybridRag.git
cd HybridRag
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python ingest.py
python main.py
